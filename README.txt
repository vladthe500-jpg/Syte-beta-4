# РМП / Военный комиссариат — сайт

Откройте `index.html` в браузере. Сайт не требует сервера или дополнительных библиотек.

Возможности:
- адаптивная версия для ПК, планшета и телефона;
- фиксированная стеклянная навигация сверху;
- плавный скролл;
- автоматическая подсветка текущего раздела;
- мобильное меню;
- кнопка возврата наверх;
- тёмный минималистичный дизайн;
- декоративная SVG-иллюстрация на главной странице;
- все предоставленные материалы размещены по разделам.
